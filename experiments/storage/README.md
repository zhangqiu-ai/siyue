# SQLite 受限 PoC

目的：为 SY-003 提供本机 SQLite 适配可行性证据。测试夹具不导入正式业务包，不实现完整目标命令，也不证明生产同步、审批、撤权或真机体验通过。

所有数据库只创建在 `os.tmpdir()` 下的独立 `siyue-storage-poc-*` 目录，测试结束关闭连接并清理本次目录，不读取应用数据库或用户数据。

从仓库根目录运行：

```sh
node --test experiments/storage/sqlite-poc.test.mjs
```

需要提供内置 `node:sqlite` 的 Node。覆盖磁盘关闭重开、对象/事件/回执原子提交与逐点故障回滚、丢响应后重试及参数冲突、双连接写锁争用、账号文件与空间键隔离、复合外键拒绝跨空间引用、升级失败回滚、新版本拒绝打开并保留原数据。

结果与限制：见 [运行证据](results.md)。SQLite 同步事务仅供适配验证；最终应用需要自己的授权、输入校验、事务作用域和错误展示。当前测试使用默认 journal 模式，未证明 WAL、进程强杀、磁盘耗尽或设备断电恢复。
