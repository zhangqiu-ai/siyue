## Context
正式移动入口为聊天/侧栏/设置/AI 服务，桌面为目标工作台。按 M 级进行视觉验收，配置防丢修复采用标准规格记录。保持现有页面结构，不引入新流程；保护弹窗为原生 Alert，设计如下：

配置页有修改 → 返回/选择其他供应商 →「舍弃未保存的修改？」
                                            ├ 继续编辑：留在原页，所有输入保留
                                            └ 舍弃修改：执行原返回/供应商切换
无修改 → 原操作直接执行；保存/移除进行中 → 等待完成，避免未知写入结果。

这是对 UI-I04 已明确预期的局部恢复，不要求另做全套新页面原型。技能审查服从项目系统字体/黑白灰约束。

## Decisions
用 expo-symbols 的 SF Symbols / Material Symbols 替换随字体变化的 Unicode；沿用已安装 SDK 兼容版本，显式声明公共依赖。必要边界与装饰分隔线区分 token。使用导航 usePreventRemove 覆盖返回与手势；不把密钥草稿写入磁盘。不自动保存，不改变配置成功后的聊天清空行为。

## Risks and Validation
模拟器实际验证明暗、375宽、大字号、键盘、空配置、搜索及取消舍弃；桌面隔离真实 Electron 验证窄窗口/200%/长记录/键盘。平台未跑分别记录。真实供应商/私人数据不用作截图。无schemaVersion变更与数据迁移；恢复只需撤回UI源码，不触碰个人数据。

## 同期设备规则更新
审查期间 DESIGN.md 与 AGENTS.md 加入 iPhone/iPad 同时适配规则。采用760逻辑尺寸最大内容宽度，在窄窗口缩至100%，不引入分栏/新导航；iPad使用现有pageSheet弹层，补横竖屏与键盘检查。同期其他文档改动由并行任务产生，保留。
