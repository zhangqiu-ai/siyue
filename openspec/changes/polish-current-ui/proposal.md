## Why
2026-09-07 全项目 UI 审查发现移动字形图标、热区、边界对比与字号不符合新基线，桌面存在窄窗口压力问题；AI 配置返回和切换供应商会丢失未保存输入。

## What Changes
- 在既有黑白灰方向内统一当前移动聊天、侧栏、设置及桌面目标工作台的图标、间距、圆角、排版、边界与焦点。
- AI 配置离开及切换供应商时，对实际未保存修改提供继续编辑或明确舍弃选择；忙碌保存/移除时阻止离开。
- 聊天上翻时提供回到最新消息按钮，保留已有自动滚动行为。
- 不新增页面、业务域、供应商请求、持久化聊天或桌面主题系统；历史隔离 QA 页面不作为生产 UI 改版。

## Capabilities
### New Capabilities
- `current-ui`: 当前界面的视觉可操作基线与配置编辑保护。
### Modified Capabilities
无已迁入的相关现行规格。基线来自当前源码、DESIGN.md 与历史 UI evidence，不追溯宣称全端验收。

## Impact
移动 UI、桌面 renderer、expo-symbols 直接依赖（已有传递版本）、UI 验证证据。无数据库/契约变更。关联 SY-009 / SY-021 的现有 UI，不升级工作包完成状态。
