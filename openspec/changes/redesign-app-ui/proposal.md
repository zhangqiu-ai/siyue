Target release: 0.0.1

## Why

2026-09-25 维护者审查账号页面后认为现有界面“没有设计感，交互愚钝”，随后要求对账号、AI 对话、空间、计划创建和白板整体重构，并明确项目未正式投产，历史界面不考虑兼容。调研发现的共性问题：每个功能都是一个长页面堆满同权重按钮和说明；看不出当前账号和空间；对话记录只存在内存里；计划草稿在未保存时确认按钮直接消失；白板只有一块写死的画板，自动保存和手动“保存”并存；五设备家庭通话在界面上没有入口。重构设计已在[统一原型](../../../docs/design/prototype/README.md)中完成并获维护者通过。

## What Changes

- **导航**：侧栏改为“品牌与新对话 → 当前空间切换 → 对话、目标、白板 → 当前空间的最近对话 → 账号头像与设置”；iPad 侧栏常驻。
- **账号**：拆成登录入口、邮箱登录、三步注册、两步找回、账号首页（身份卡与分组列表）、登录方式、修改密码、登录设备（按需身份验证）、家庭责任、数据空间、三步注销与注销进度，按原型重做。
- **对话**：新对话首页（问候、按空间给出的建议、发送范围说明）、正文排版的回复、逐段生成与停止、复制与重新生成、未连接 AI 时的连接卡、网络失败后保留原文重发；**新增**对话按空间持久保存与侧栏最近对话；**新增**对话内生成计划草稿卡。
- **空间**：空间首页（空间名切换、同步状态、今天的任务、目标卡、草稿提示、新建按钮）、目标详情（日期、进度、理由、任务打勾、行内添加、已完成折叠、完成与归档）、家庭成员页、只读成员与同步冲突的就地处理。
- **计划创建**：写下目标（AI 拆解或自己填写）、骨架屏生成中、单页草稿（全部字段可改、编辑自动保存、确认按钮始终可用）、已加入结果页。
- **白板**：白板库（多块白板、名称、缩略图、三种起点）、全屏编辑（浮动栏、仅自动保存并显示状态、页面缩略图、插入菜单）、发起家庭通话与通话中界面（界面部分；通话行为由 add-family-video-whiteboard 负责）。
- 旧界面结构直接废弃，不保留切换开关；已有本地数据（目标、任务、草稿、白板存档、账号凭据）不得删除，按本变更 design 的迁移说明读入新结构。
- 非目标：设置页重做、创建家庭空间与邀请成员的完整流程、RTC 厂商接入、云端对话同步、附件与语音输入。

## Capabilities

### New Capabilities

- `app-navigation`：侧栏结构、空间切换入口、手机抽屉与 iPad 常驻侧栏。
- `account-experience`：账号相关全部页面的结构与交互。
- `chat-experience`：对话页面、生成控制、错误恢复、按空间持久保存与计划草稿卡。
- `space-home`：空间首页、目标详情、家庭成员页与同步状态呈现。
- `plan-creation`：计划创建流程与单页草稿。
- `whiteboard-workspace`：白板库、白板编辑外壳与家庭通话界面。

### Modified Capabilities

无已迁入的相关现行规格（`openspec/specs` 只有 development-workflow）。账号行为与密码规则仍以 add-shared-api-independent-auth 为准；家庭空间权限与同步以 add-account-family-spaces 为准；通话、录制与存档行为以 add-family-video-whiteboard 为准。本变更只定义界面与交互，不改变这些变更中的权限和数据规则。

## Impact

- 移动端：`apps/mobile/app/**` 路由重组，`apps/mobile/src/{ui,account,chat,space,screens,whiteboard,i18n}` 大面积替换；新增共享组件与 4 个语义色（errorSurface、warn、warnSurface、apple/onApple）。
- 共享包：对话持久化需要在 `packages/contracts` 与本地存储中新增对话与消息结构；计划草稿日期需要扩展 `GoalDraft`；多块白板需要扩展白板存档协议（由单一 `local-whiteboard` 改为白板列表）。
- 桌面端：本变更以移动端为首要交付；桌面按同一信息结构跟进，差异在 tasks 中单列，不宣称跨端对等。
- 测试：原生 UI 自动化与既有 Playwright（桌面、HTTP）脚本随路由和文案更新。
- 工作包：关联 SY-021（AI 对话）、SY-023（白板试用）、add-account-family-spaces 与 add-shared-api-independent-auth 中的界面任务；本变更不新建 SY 编号，用 tasks 编号跟踪。
