## Context

基线为 `feature/dev` 提交 `8baacbc4c702f86576358d02e76e45536447334f`。本文件是待评审工程/交互设计，不代表 SDK、设备或网络已经验证。已确认范围仅以 [proposal C01–C11](proposal.md) 及既有产品约束为准。

## Goals / Non-Goals

目标是可日常使用的五设备家庭互动闭环，同时支持题图讲解和直接书写。本地完整作品与录像不是同一对象。非目标沿用 proposal；任何验证结果不自动授权付费、迁移或扩大数据用途。

## Decisions

### 1. Baseline：房间、白板、存档与录像分开

- `CallSession` 表示一次互动；`BoardDocument` 可以跨多次互动继续使用，结束房间不删除作品。
- `RoomDevice` 绑定已验证身份、房间及设备会话；同账号两台设备占两个名额。重连使用服务端验证的原设备会话，不信任客户端自报 deviceId 绕过五台上限。
- `ArchiveAssignment` 指定主存档设备及授权版本；主存档与音视频转发、当前讲解者、录像发起设备不是同一个职责。
- `RecordingSession` 独立表示录制者、采集范围、状态与文件结果。录制范围已按 C10 确认；同意流程仍依 O02 定案。
- 采用少量平台中立契约与适配端口；RTC/白板/文件 API 不进入 domain/contracts。复用既有账号会话和家庭授权，不为 PoC 建第二套生产身份系统。

### 2. Baseline：五设备接入与协作

由服务端原子分配设备名额，满员拒绝第六台而不挤掉已加入者；并发加入、断线旧连接迟到、重连重复请求均需测试。名额保留/释放时长由验证决定，规格不虚构秒数。不得通过静默踢人来满足上限。

Confirmed（C11）：仅家长发起，邀请已有家庭成员，不提供公开房间码；儿童可接受邀请；发起者离开不结束通话，家长可明确结束全场。逐人接纳、移除及邀请委托细则仍见 O01。家庭身份本身不自动授权读取本次作品。

共同书写与观看权限分开。建议成员能撤销自己的操作；整页删除/清空需权限与确认；讲解者可邀请视角跟随，成员可自由查看并返回跟随。具体权限仍由 O03/O04 确认，不把这些建议标记为用户已经拍板。

### 3. Baseline：两种输入共用一张可编辑白板

图片、裁剪/旋转变换、页面与笔迹分别存储，笔迹使用统一文档坐标；不以屏幕像素直接跨设备定位。建议支持画笔/橡皮、粗细颜色、撤销重做、平移缩放、增页及基础图形；具体工具清单按 O04 冻结。

拍照/选图在通话流程内完成，取消不产生空题页。相机争用必须真机验证：拍题期间音频、前摄预览、对端提示与拍完恢复分别记录，不预先承诺前后摄同时工作。不做 OCR 也能拍题讲解。

协作基线为稳定对象 ID、操作 ID、作者/设备、权限版本和序列；笔迹、图片资源与页面变更可对账。晚加入者读取获授权当前快照及增量，缺图片时明确加载失败，不能显示空白却假装同步成功。选定 SDK 前比较可靠操作流与成熟协作引擎，不预先锁定 CRDT 或另建通用同步系统。

### 4. Baseline：本地保存的权威与失败状态

用户选定设备保存完整题图、对象及页面；“本机已保存”“主存档已确认”“实时操作未同步”分别显示。收到网络包、显示出笔迹或生成缩略图，都不能当作持久化成功。

建议按 `boardId + revision + schemaVersion + manifest` 原子写入快照与附件引用，校验资源完整性；中断保留最近完整版本和可恢复的受控临时数据，不覆盖唯一原件。文件写入、空间不足、应用被杀、损坏/未来版本均测试。

主存档断网时不自动把另一成员设备升级为永久保存者。显示主存档中断和未确认修订；恢复后对账。是否允许继续编辑、临时加密恢复副本、接管授权与清理时机属于 O03。O03 未决时只做隔离失败验证，不发布会静默丢数据的协作路径。

其他设备缓存仅为本次获授权协作，不等于永久另存授权。原家庭 24 小时离线租约不能直接当作通话名额、录像同意或永久导出授权；相交行为需对照原规格。

另存需明确权限、范围、接收设备和结果；已导出的离线副本不能承诺远程强制收回。用户必须看到本机删除和其他持有者副本的区别。换机没有本地副本且没有云库时，不承诺登录即恢复。

### 5. Baseline：录像独立且不得静默降级

默认关闭，家长主动发起；首次采集前完成按 O02 确认的告知/同意。录制中持续向当前及中途加入者显示谁在录制、录制范围；授权/状态通知失效时采取停止或阻止开始的安全策略，具体流程需评审。

Confirmed（C10）：有白板时以白板为主画面、参与者视频为小画面，包含本地及远端声音；无白板时记录多人视频及声音。该确认不包含同意流程、中途加入或多设备录制规则。分别验证本地/远端音频、多路视频、白板合成、音画同步、来电/后台/中断、文件封装与恢复，不能将 SDK 的本机摄像头录制接口当作全房间录制。

录制失败只影响录像，不强制结束通话和白板；显示失败而非继续伪装录制。默认保存在获授权录制设备应用空间，不自动发到所有参与设备、系统相册或云端。多设备同时录制、容量上限和删除规则均属 O02/O03。

### 6. Baseline：布局和设备

沿用仓库 DESIGN.md 及现有组件；不重新选择主题或 UI 框架。Figma 交互确认后才实施正式页面，本轮不创建视觉稿。

手机紧凑布局保留当前重要视频与参与者入口；iPad 横竖屏/窄窗口兼顾视频区与书写区，支持固定关注对象，不让说话切换不断遮挡白板。Android 手机/平板与 Electron 按平台输入能力分别验证；桌面录像/房间角色的首发矩阵见 O05，不擅自延期或宣称功能对等。

所有操作、权限、失败、恢复和录制提示覆盖中文/英文、无障碍名称与适用大字号。真机摄像头/麦克风/手写笔/后台/录制不能用浏览器或桌面 E2E 替代。

### 7. Validate：国内服务与成本

仅确认国内厂商方向，未确认 RTC/白板供应商。候选比较依据：当前 RN/Expo、iOS/iPadOS、Android、Electron 兼容实证，五路接入、本地合成录制、白板持久化/导出、自有题图分发、国内实网与退出路径。

逐数据类登记服务接收方、地域、传输/暂存/长期保存、期限、删除接口及 SDK 日志。关闭云端录像不证明白板、图片或日志零留存。个人密钥、家庭照片与原始影音不进入仓库、测试日志或 AI。

预算分列音视频用量、白板、临时分发、控制服务及原账号服务；记录计价口径和实测情景，不把历史 200 元账号预算当新增 RTC 授权。费用限额及服务购买见 O06。

## Migration Plan

规划交接后先实施 experiments/video-whiteboard 中的隔离技术验证，不改生产业务 schema 或数据。未来新增协议采用独立 schemaVersion，不与产品 0.0.1 混用；冻结前记录兼容读写范围。白板升级先复制验证，失败保留旧原件；不支持的未来版本只读拒绝或明确报错，不覆盖。实现回滚禁用新入口但不删除已保存作品；历史个人空间/目标数据不迁移。未来云存储另立变更并要求显式选择上传内容。

## Risks / Trade-offs

本地优先减少长期云归档需求，但不保证零服务费用、零暂存或自动跨设备恢复。五设备通信、本地合成录制与手写同时运行的性能未经验证。默认让所有设备永久保存虽方便，却违背 C08；仅主存档持久化又需处理主设备中断，不能掩盖这个取舍。

## 独立白板试用原型（2026-09-20）

按本地维护者要求先开放无通话的可操作测试页。此原型复用已确认Sage主题：顶栏返回/本机保存，工具区画笔、整笔橡皮、撤销/重做、颜色粗细，主体固定1000×1400文档坐标的等比画布，页签及空白/示例题页入口。iPad同坐标等比放大，不拉伸笔迹。示例题图由本地资源提供，无相册访问或网络传输。工具与示例内容均提供中英。

试用数据使用独立SQLite KV键，单个有界JSON文档写入，读入严格校验；保存失败保留内存编辑，未知格式禁止覆盖，离开未保存编辑给出继续/舍弃选择。该数据不进入家庭正式记录，不是2.4 Node文件归档适配完成，也不冻结协作/另存/接管规则。此页本身是本次可操作原型，正式全流程仍按3.1设计评审推进。原生交互采用可用自动化验证；Playwright不覆盖原生画布时不得伪称浏览器替代原生。

## C12 · Excalidraw 实际编辑层（2026-09-20）

维护者明确采用 `@excalidraw/excalidraw@0.18.1`。正式本机入口只使用此编辑器，旧自研屏幕保留为不路由的回归源文件，不再扩展其绘制/命中检测/撤销能力。旧的组件选型候选在本轮不再适用。

移动端 `app/whiteboard.tsx → WhiteboardScreen → 'use dom' EditorDOM → @siyue/whiteboard/editor`；Electron 首页白板入口复用同一个 Editor。编辑器内处理笔迹、手势、选择、缩放、图片与撤销栈。原生宿主只处理导航、安全区、相机/系统相册、图像规范化和 SQLite。没有公共协作服务器、真实家庭图片外发或 AI 识题。

桥接版本 1，以 session/requestId 绑定请求，只支持 load/save/pick/legacy。禁止任意路径、脚本、密钥与通用模块代理。保存请求携带基准修订、页面及新增图片文件；高频 onChange 只更新 DOM 内存。600ms 合并与 2s 最长定时落盘并存，切页、返回和正常 Electron 退出等待确认。后台触发尽力保存；强杀只能保证最后收到成功回执的修订。失去响应时保存以同一请求身份重试一次；并发过期修订拒绝，不能盲目重载覆盖内存内容。

格式 v2 包含稳定文档/页面 ID、Excalidraw 元素、图片 dataURL 字节/引用及白名单背景色/scrollX/scrollY/zoom。SQLite 同步原子替换完整记录，失败不替换。坏 JSON、未来格式、缺图与非法元素在读取或提交前拒绝，不能降级为空白后写回。每页挂载独立 Excalidraw 实例，迟到旧页 onChange 被忽略，撤销历史不跨页。根据 C13，旧 v1 仅为弃用的开发记录，正式入口不读取或转换，也不展示迁移提示。现有 v2 存档保护不变。

原生选图最大输入 32MiB / 80MP，长边大于 3200px 时在新文件上缩小，JPEG 质量 0.92，导入文件上限 8MiB。相机原件复制到应用私有目录保留，画布使用规范化副本；相册原件不修改。图像在画布中是可移动/缩放的元素，不是固定画板边框。

代码、CSS 与字体均来自安装依赖并本地打包。Expo 57 Metro 的 CSS 条件导出解析与 DOM common chunk 导出错误已有复现，分别以精确 CSS resolver 和关闭 DOM bundle splitting 解决，未替换编辑器、升级 SDK、修改 node_modules 或启用通用原生代理。具体构建与运行证据集中在 [Excalidraw 接入证据](../../../docs/evidence/excalidraw-integration-2026-09-20.md)。

隐藏在线素材库及不受控导入/导出菜单；图片只走原生选择，链接/嵌入/粘贴外部内容被禁止，CSP 限制资源为本地。此本机入口没有多人另存授权，不可冒充主存档设备。未来协作应在独立房间适配层接入元素版本及资源同步，不改变 DOM 内部逐点绘制的归属。

录像仍采用已确认的白板主画面＋参与者小画面＋双方声音；DOM/WKWebView/Android WebView 合成表面能否被连续捕获并与 RTC 画面、音频同步尚未验证。截图导出不等于连续录像，本轮不扩展录制实现。
