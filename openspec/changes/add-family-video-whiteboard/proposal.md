## Why

维护者将多人家庭视频通话与共享白板提升为思玥当前首要开发目标。现有工程具备部分个人空间、身份与家庭权限基础，但原账号家庭提案明确不自动包含视频白板，不能用原任务完成状态代表本功能进度。

本变更交付闭环：发起家庭互动 → 最多五台设备加入 → 视频中拍题或打开空白页共同书写 → 本地保存可编辑白板 → 下次继续。个人成长主线与 AI 增加高质量人际互动的原则不变。

Target release: 0.0.1

## What Changes

已确认范围（2026-09-20，维护者在本次对话逐项确认）：

| ID | Confirmed |
|---|---|
| C01 | 当前 P0 主线；继续使用未发布的 0.0.1。 |
| C02 | 多人参与，每房最多同时五台设备，含发起设备；不是五个账号或家庭成员总数。 |
| C03 | 暂以中国用户为主，视频白板相关云服务采用国内厂商方向；具体厂商未选。 |
| C04 | 首版本地长期保存，云端作品库、录像备份后续再接入。实时传输不等于云端长期归档。 |
| C05 | 纸上作业拍题共同讲解为主；直接在白板上书写和练习同样属于首版，不能延期成只看图片。 |
| C06 | 默认不录制；家长手动开启本地录像，所有参与者持续看到录制状态；停止录像不结束通话或白板。 |
| C07 | 白板独立于录像保存，包含题图、可编辑笔迹及页面结构，而非仅截图。 |
| C08 | 发起活动的家长指定主存档设备自动保存；其他参与者按权限另存，不默认全部永久保留。 |
| C09 | 保存位置不限制获授权成员共同书写；明确“已保存到本机”，不暗示云备份。 |

延续已有约束：React Native + Expo、Electron + React；中文/英文；iPhone/iPad 同时设计与验收，Android 支持保留，桌面按既有产品边界及本变更确认矩阵验收。

本轮产出是规格草案、技术验证计划和开发任务，不是功能实现。新增的操作权限、房间入口、录制画面、存档接管等具体建议标为 Baseline / Owner decision，见 [design.md](design.md)。

非目标：不把 AI 实时旁听、OCR/自动判题、公开会议平台、支付、全域自动记忆、通用云同步框架、完整课件系统加入本切片；不购买或部署服务，不迁移真实家庭数据，不自动开启云端录像。云端白板临时留存、图片分发等仍须审查，不能承诺完全不经过云或零留存。

## Capabilities

### New Capabilities
- `family-video-call`: 五设备房间、受控加入、视频白板共存、退出与重连。
- `shared-homework-board`: 拍题与空白书写、可编辑对象、多人协作与恢复。
- `local-session-archive`: 指定设备归档、权限另存、本地手动录像、恢复和数据控制。

### Modified Capabilities
不改写已验收现行规格；本次差量仅保存在本活动变更内。原家庭身份、共享授权与离线租约的复用边界先对照活动账号家庭变更核实。

## Impact

- 优先级：本主线高于旧 M1 初始化顺序及非依赖的新功能扩展；仅补通话所需身份、成员、授权和本地保存链路，不等待全部个人成长或通用同步功能完工。
- 旧任务：保留已有代码、设计和验收事实；原 0.0.1 未验收项不删除、不标完成、不自动改版本或宣布延期。若发布范围要进一步缩减，由维护者另行决定并记录去向。
- 工作包：当前 SY 清单没有本功能的完整独立工作包。本轮以本变更 [tasks.md](tasks.md) 的稳定编号跟踪，不伪造 SY 或 GitHub Issue 编号。依赖复用 SY-001/002 的工程契约，以及 SY-003/004/005 和账号家庭变更中的必要存储、身份、权限能力；这些旧工作包的整体完成不作为所有独立验证的前置条件。产品待决项收敛后再同步新增 SY 到 Markdown/JSON 两处。
- 模块：`apps/mobile`、`apps/desktop`、`apps/server`、`packages/domain`、`packages/contracts`、`packages/adapters`；不新增平行账号体系或通用同步引擎。
- 地域：新国内优先要求替代视频白板服务继续按历史海外候选选型的方向，不等于现有账号/同步已迁移。原账号/邮件/同步 200 元月预算不自动成为音视频新增预算；报价和限额另审。
