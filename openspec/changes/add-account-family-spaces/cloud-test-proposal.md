# 真实账号隔离验证资源提案

Target release: 0.0.1
状态：待维护者确认外部测试资源；不是正式生产选型。

## 建议批准的具体动作

1. 在维护者指定/已登录的 Supabase 账号下创建一个专用 Free 项目，名称 `siyue-001-auth-validation`，地域 Tokyo（ap-northeast-1）；若免费项目名额或该地域不可用，停止并报告，不升级/替换地域。
2. 仅用于合成计划数据和维护者指定的测试邮箱。配置邮箱 OTP 验证码模板（非仅 magic link），并接入现有服务端 session 验证边界。不得导入现有本机用户内容或改变空间归属。
3. 首轮只向维护者明确指定且符合项目团队限制的邮箱发送不超过两封验证码，验证真实收件、正确/错误/重复码与会话摘要。未给测试邮箱前不发信，不为绕过限制将普通家人加入项目管理团队。
4. 自定义 SMTP 后续采用候选 Resend Free：先由维护者给现有发信域名和允许的测试收件人，再给出具体 DNS 配置审核；本提案不授权改未知域名 DNS、购买域名、注册付费套餐或群发邮件。

项目创建的基础订阅目标为0元；若出现付费、自动升级或绑卡要求，停止。完整首版200元/月预算仍需包含API、邮件、同步、备份和域名，不因本测试免费而声称整套费用可控。

## 可交付结果与失败处理

记录项目地域、公开项目标识、配置方式和脱敏测试结果；密钥仅放服务端受控配置，不进入Git/日志/截图。实际会话验证以供应商验证后的身份为准，不仅解码JWT；核对撤销/过期语义，不能用旧令牌声明当前家庭权限。

首轮验收：真实验证码投递与验证、错误/重放拒绝、同邮箱身份稳定、服务端session端点拒绝伪造/失效身份。大陆与海外分别进行设备网络与邮件实测，当前单台Mac网络不能证明双地域可用；测试邮件额度不足时等待额度，不自动重发或升级。

儿童身份、家庭事务、跨设备同步、撤权与离线24小时仍属于完整目标，未被本轮成人账号验证替代。PowerSync是否采用、邮件域名、生产托管、备份恢复仍待实际验证，暂不购买或部署。

本机PATH中的 `command -v docker`、`command -v supabase`、`command -v psql` 均未找到可执行程序；这仅证明当前Shell不可用，不断言整个机器未安装。没有安装软件、下载容器或启用服务。
