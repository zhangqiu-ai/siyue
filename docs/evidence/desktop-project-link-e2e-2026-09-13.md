IPC 仅接受两个严格参数、恰好一个项目和无额外身份字段的请求。共享历史 schema、`saveManual` 恢复键和旧记录均未改变。真实 SQLite 恢复测试验证首次已创建 ui 草稿但返回丢失后，同 request 重试返回相同草稿；正式目标、项目、任务仍为零且没有执行回执。
