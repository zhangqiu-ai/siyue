# 家庭权限领域内核

范围：0.0.1 / add-account-family-spaces / 7.x。将已批准的共享权限从隔离实验落实为 contracts 与 domain 模块；不修改现有 SpaceState 或数据库，不部署、不发验证码、不增加公网入口。

## 信任边界

`evaluateFamilyPolicy` 只接受服务端已验证身份与同一事务中读取的当前快照。严格 Zod 校验只证明结构，不证明调用者身份或权限来源。调用方仍须处理对象版本、原子事务、回执、唯一所有者、共享目标资格和撤权传播。内部拒绝原因不可直接用作公共资源存在性响应。

个人上下文仅原件所有者具有读取、编辑、共享、撤销与删除资格；家庭上下文仅开放 read/edit，并要求同家庭成员与精确原件授权。共享编辑要求成员版本及授权版本匹配。家庭管理与原件所有权分开，儿童会话不拥有家庭管理资格；管理员不能转移、解散或移除所有者/管理员。

## 独立审查

主代理检查原始实现，要求修正两点：授权前不能 trim ID 从而将不同标识归一；允许结果不能是共享可变对象，避免调用者修改一次返回值污染后续裁决。重复成员/授权身份必须拒绝，不能挑选其中一条旧授权通过。

验证结果将在实际包测试与构建结束后记录。该内核通过不等于真实账号、服务端事务或家庭同步完成。

## 实际验证

先运行测试得到缺少实现模块失败，再实现通过。仓库根目录执行 `corepack pnpm --filter @siyue/contracts test` 10/10、`corepack pnpm --filter @siyue/domain test` 49/49，通过日志分别为 `/tmp/siyue-family-contract-tests.log`、`/tmp/siyue-family-domain-tests.log`。按 contracts → domain 顺序构建通过，`corepack pnpm spec:check` 与 `git diff --check` 通过。

主代理实际读取最终裁决模块并核对同一原件的空间/ID匹配、当前成员/授权版本、角色/儿童/目标保护和独立返回对象。没有修改生产数据库、部署、提交或推送。纯内核测试未证明 V04/V18 的真实服务端/设备路径完成。
