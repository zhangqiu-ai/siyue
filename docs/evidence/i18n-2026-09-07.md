变更：[add-zh-en-localization](../../openspec/changes/add-zh-en-localization/proposal.md)。级别 M：现有 UI 的双语资源化、设置入口与本机偏好，无业务/存储协议变更。沿用黑白灰和当前布局，未增加依赖。

## 实现与决定

- 移动与桌面设置提供「简体中文 / English」。默认简体中文保持原体验，选择即时生效，保存非敏感 `siyue.locale` 偏好；未知值回中文。默认/变体是本次实施基线，用户明确授权双语及设置切换。
- 文案覆盖聊天、AI 配置、供应商列表、桌面目标/草稿/任务、状态、安全错误与无障碍名称。资源类型和测试检查完整性、参数一致性；计数使用 Intl.NumberFormat。
- 语言切换不重建业务 provider。用户文本、模型 ID、地址、AI 返回不翻译；连接测试仍发送原本的“请只回复 OK”，英文提示准确说明原文。
- 偏好读取失败回中文并提示；写入失败保留会话选择并提示，支持重新选择重试。未知错误不直接展示原始内容，避免泄露密钥。
