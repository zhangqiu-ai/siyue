# SA-08 受控家庭邀请 · 2026-09-24

工作树：`feature/dev`，保留既有未提交改动。本批为隔离的本地服务端实现和验收；没有连接生产数据库、发送真实邮件、提交、推送或部署。

`0010_family_invitations.sql` 增加一次性邀请记录；服务端新增创建和接受接口，沿用已验证的成人会话、现有家庭策略快照及数据库角色。只有当前 owner/admin 能按所读成员与家庭版本创建 24 小时邀请。服务端生成 32 字节随机令牌，长期只存其 keyed digest；同键恢复所需密文至多保留 60 秒，并在接受、到期或定期清理时销毁。定向邀请将规范化的目标邮箱存在邀请记录中；接受者必须拥有同一已验证、可登录的邮箱及密码凭据。未指定邮箱的邀请仍须由登录成人持有令牌并一次性接受。接受时重新核验邀请者角色、成员版本和家庭版本，只新增普通 `member`，不授予监护、记录、白板、房间或录像权限。

HTTP 路径为 `POST /v1/families/{familyId}/invitations` 与 `POST /v1/family-invitations/accept`。两者都要求 Bearer 会话和 UUID 幂等键；创建体只含可选目标邮箱、预期成员版本和预期家庭版本。没有增加公开房间码或产品界面入口。审计记录仅含主体、会话、邀请 ID 及拒绝原因，不记录令牌或目标邮箱。

验证：`corepack pnpm build:packages` 5/5、`corepack pnpm --filter @siyue/server build`、`corepack pnpm typecheck` 13/13、合同测试 39/39。针对邀请及家庭仓储的独立临时 PostgreSQL 集成测试 27/27，覆盖 0009→0010 增量迁移和最小权限、角色与版本拒绝、撤权后同键不可恢复令牌、目标邮箱验证、过期和销毁、同键/异键重试、并发争抢、事务回滚和审计内容。全量服务端集成 146/146。真实 Fastify + 临时 PostgreSQL 的 Playwright HTTP 测试 `tests/e2e/families.spec.mjs` 4/4，覆盖定向创建、错误账号拒绝、一次性接受、成员权限限制及邀请者版本变更后拒绝。`corepack pnpm spec:check` 6/6、`corepack pnpm release:check`、`git diff --check` 通过；新增未跟踪文件的尾随空白扫描也无命中。所有测试使用合成身份和隔离数据。

本批只证明本地服务端和 HTTP 行为；尚无产品内邀请界面、真实邮件/分享交付、监护与儿童设备配对、房间/白板授权接线，亦未验证真实多设备视频。SA-08 的 9.3～9.4 及整体验收继续开放。
