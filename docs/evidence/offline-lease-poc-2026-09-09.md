# 离线租约隔离实验 · 2026-09-09

Target release: 0.0.1。关联 `add-account-family-spaces` / V07。

范围：`experiments/account-family/offline-lease.mjs` 与同目录测试。没有接入应用、签发真实授权、选择供应商或读取个人数据。

执行：仓库根目录 `node --test experiments/account-family/offline-lease.test.mjs`，5 项通过。覆盖到期前一毫秒/到期瞬间、墙钟调回、重复使用不续期、进程变化、单调计时倒退、非法计时值、跨账号/空间、服务端缩短期限和拒绝超长授权。

结论：可以用进程内不可变单调时间锚点表达已确认的到期规则。进程重启后没有可验证连续时间，实验选择锁定并要求重新核验，符合“无法证明有效时锁定”。实验输入假定已经完成服务端身份与授权校验；不能直接接受客户端提交的 grant 或 processId 作为可信授权。

未验证：真实平台计时源是否包含休眠时间、系统重启/进程恢复、令牌验签、可信存储、服务器签发/撤销、原生数据锁定与受控输入恢复。计时源必须包含休眠耗时；不能直接把暂停期间停止的 JS 计时器用于本方案。当前测试由确定性时钟输入驱动，不能证明 iPhone/iPad/Android/Electron 的 V07 通过。
