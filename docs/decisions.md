## 变更规则

修改 Confirmed 约束必须取得用户明确指令。Baseline 可以在有证据的情况下调整，并记录原因与替代影响。Validate 不能在 README 中写成“已支持”。所有决定记录日期、提出人角色、证据、状态和影响；禁止以助手的个人推荐冒充用户已拍板。

本次未向旧仓库提交代码，也不把旧仓库的 AGENTS 或产品规则自动升级为本项目规则。
