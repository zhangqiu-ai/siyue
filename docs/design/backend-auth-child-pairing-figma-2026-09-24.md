# 儿童设备配对 · 交互草稿

状态：Figma 低成本流程草稿，等待维护者确认结构；不是已接入的产品界面。

[Figma 草稿](https://www.figma.com/design/5OKY7OMJ2jQy2XAaGbNDGC?node-id=634-43) 沿用 Sage 明暗语义变量和现有主按钮组件。已实际查看 [iPhone 儿童等待画面](../evidence/backend-auth-child-pairing-2026-09-24/child-waiting-iphone-draft.png)、[iPhone 家长批准画面](../evidence/backend-auth-child-pairing-2026-09-24/guardian-iphone-draft.png) 与 [iPad 英文暗色画面](../evidence/backend-auth-child-pairing-2026-09-24/guardian-ipad-dark-draft.png)；后者经一次列宽修正，内容限制在 560 宽并居中。

| 状态 | Figma 节点 | 目的与后续行为 |
| --- | --- | --- |
| 儿童设备发起 | `634:44` | 未登录设备显示设备描述，发起五分钟配对申请；不要求儿童邮箱或家长密码。 |
| 等待家长 | `634:54` | 显示仅含 `pairingId` 和 `requestToken` 的二维码、倒计时和取消入口；`pollSecret` 只保留在发起设备。当前图中的二维码是草稿占位，不能扫描。 |
| 家长核对并批准 | `634:65` | 已登录家长扫描后，服务端预览设备描述；选择实际监护的儿童，核对后再次验证并批准。预览本身不消费再次验证授权。 |
| 儿童设备完成 | `634:80` | 发起设备用本机秘密领取受限儿童会话，并在安全存储成功后才显示完成。初始授权不包含房间、白板或记录权限。 |
| 家长设备管理 | `634:90` | 列出实际监护儿童的设备；撤销前确认，撤销后下一次请求立即失效。 |
| iPad 英文暗色 | `634:100` | 检查英文长度、暗色层级和受限内容宽度；正式验收仍需横竖屏及窄窗口。 |

流程中的拒绝、过期、断网、再次验证取消、领取响应丢失、撤销失败都应就地显示状态，保留安全的重试入口；不显示家长凭据、轮询秘密或原始服务端错误。一个申请只批准一次，领取结果未知时在 60 秒窗口内用原秘密恢复，不能生成第二个儿童会话。桌面家长端沿用同样的信息顺序；Android 儿童设备沿用同样的发起与领取边界。正式 UI 要接原生扫码或受控的跨设备交付，不把秘密写入公开日志或 URL。

待维护者确认的是这套页面顺序和信息层级。儿童主体创建需要向家长展示正式监护同意文本及版本；仓库当前只有记录接口，没有可供产品确认的政策正文，因此本草稿假设儿童已由有权家长创建，未画或开放“创建儿童”表单。具体扫码控件、儿童列表和再次验证面板仍需依据现有客户端能力实现；原生扫码、双语、明暗、iPhone/iPad/Android/桌面操作及无障碍尚未验收。
