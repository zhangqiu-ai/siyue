# 账号与家庭空间交互预览

直接打开 [index.html](index.html)，或从项目根运行 `python3 -m http.server 4179 --bind 127.0.0.1 --directory docs/design/account-family-preview`，访问 `http://127.0.0.1:4179/`。不依赖 CDN、字体服务、外部脚本或新增生产依赖。

这是 70 个场景的本地设计预览，待维护者评审；Figma 手机384张及平板768张已补齐并完成静态和路由检查，完整设计待维护者评审，详见[交付清单](../account-family-ui-completion-2026-09-09.md)。可用顶部场景选择器检查全部状态，再切换语言、主题和视口。支持 URL 参数 `scene`、`lang=zh|en`、`theme=light|dark`、`layout=auto|phone|tablet`，仅控制评审视图。

## 设计来源

- 已批准的 R3 蓝灰焦点卡、分组列表、克制状态色；沿用 Figma 的 iOS/iPadOS 26 组件语法。
- 预览以原生 HTML 按钮、输入、选择器、复选框和对话框重新表达交互，**不是 Figma 原生组件本身**。
- 图标来自本轮已获取的 Lucide SVG，内嵌于 content.js。
- 系统字体、无手机硬件假框；宽度不足 820 时为单列，宽度达到 820 时显示侧栏与内容区。
- 外部评审栏提供全部场景、语言、主题、视口与重置。

## 可操作流程

- 登录邮箱格式校验 → 六位验证码（仅 `123456`）→ 选择本机内容 → 保留已有内容的空间首页。错误验证码不会进入账号。
- 聊天可输入 → 草稿各任务可编辑 → 保存修改返回草稿 → 明确确认才出现保存成功与正式目标。目标勾选立即更新进度。
- 成员移除、转移所有权、设备撤销、共享撤销、解散家庭、归档与退出均有确认弹窗。
- 移除 Sam 后成员列表与数量更新；转移后 Sam 为所有者，Alex 为普通成员，监护关系不变。
- 儿童设备撤销后必须重新配对；儿童首页无家庭管理员功能。
- 会话共享始终使用「讨论本周阅读」。可选择查看/编辑，切换预览身份为 Sam 时，查看权限不显示输入器。
- 重连仍保留冲突；选择 15/20 分钟或手动合并后显示对应任务。恢复输入另存私人草稿，保留原内容。
- 有未发消息时切换空间提示保存私人草稿或取消。
- 设置有中英文与明暗主题入口；全部场景随语言/主题切换。

## 状态与边界

所有状态只保存在当前页面内存中。刷新/重置恢复合成样例；未采用 localStorage，以免把体验者输入持久化。退出清空会话与私人草稿状态。工具条始终标明原型性质及演示验证码。

本原型没有真实账号、邮件、AI、后端、权限执行或云同步，界面中「已同步」是待评审的产品状态文案。场景选择器可以直接进入异常/完成态，并非绕过正式业务权限的生产入口。

账户删除保留政策尚未确认，停留在待确认说明页，不模拟真实删除成功。离线到期、撤权、发送未知等异常界面来自本轮中英状态文案；部分通用异常场景通过返回/重试导航展示，没有真实计时或网络故障注入。
