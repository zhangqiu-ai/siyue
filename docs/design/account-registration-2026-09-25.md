# 邮箱注册：设计与接线

维护者于 2026-09-25 授权自行决定细节并完成真实线上注册、登录、注销。本轮沿用已确认 Sage 方向；注册分为邮箱及协议同意、验证码及密码两个步骤，不改变既有登录与注销流程。

[Figma 设计页](https://www.figma.com/design/5OKY7OMJ2jQy2XAaGbNDGC?node-id=642-79)：iPhone 邮箱 `642:80`、iPhone 验证 `642:91`、iPad 验证 `642:113`、英文暗色 `642:135`。复用 semantic collection `547:44` 和 Primary Button `548:33775`，iPad 表单最大宽度 460。设计写入返回结构和 iPhone 验证页截图已检查，未发现裁切；设计检查不替代原生运行。

- 协议默认未勾选，链接来自服务端已发布版本；未发布或不可读取时禁止发验证码，并提供恢复入口。原生勾选区域与协议链接各自独立，最小点击高度 48，避免嵌套链接截获勾选操作。
- 密码 15–128 个字符；验证码六位，十分钟内有效；显示重发等待及垃圾邮件提示。
- 未知请求结果冻结可变字段，显式重试原请求；明确协议版本变更需重新阅读同意。
- 离开流程清空内存密码、验证码及证明，成功后由既有安全存储与会话控制器恢复。
- 中英文、明暗色、iPhone/iPad 和桌面沿用现有语义颜色、可访问名称及表单组件。
