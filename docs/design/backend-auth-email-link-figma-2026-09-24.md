这份草稿只定义页面层级和关键状态。Apple 原生授权面板由系统提供，草稿中的“继续”对应已接好的 Apple 再次验证和邮箱挑战；草稿本身没有可执行连接，也不是运行中应用截图。取消、授权失败、请求结果不确定、验证码过期、实际保存成功以及屏幕阅读器/大字布局仍需在正式 UI 实施和设备验收时覆盖。
