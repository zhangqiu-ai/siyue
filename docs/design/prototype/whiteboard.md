# 白板

功能 ID：`whiteboard` | 设计日期：2026-09-25 | 状态：维护者 2026-09-25 确认原型，正式 UI 尚未实施 | 原型：[siyue-prototype.html](siyue-prototype.html)（跳转面板“白板”）

## 现状问题

全应用只有一块写死的白板，没有列表、名称和缩略图。自动保存和“保存”按钮同时存在，用户分不清离开是否安全。保存、切页和导入图片时会用全屏遮罩挡住画布。冲突提示让用户“联系维护者”。五设备家庭通话是 P0 目标，但界面上完全没有入口。

## 页面

- **白板库**：卡片网格，每张有缩略图、名称、页数和最近编辑时间；最后一格是“新建白板”（空白、拍题、从相册三种起点）。家长在右上角发起家庭通话，儿童设备不显示这个入口。
- **白板编辑**：画布占满全屏。顶部浮动栏依次是返回、标题（下方显示“已自动保存”）、页码按钮（打开页面缩略图，可新建和删除页面）、发起通话、插入（拍题、从相册选图、空白页）。底部浮动工具栏有选择、画笔、橡皮、文字、形状、颜色、撤销和重做，没有“保存”按钮。
- **发起通话**：只能勾选家庭成员的设备，最多 5 台（含这台），没有公开房间码；说明默认不录制，发起人离开后通话仍会继续。
- **通话中**：参与者小窗在顶部（iPad 在右侧），正在讲话的人带描边。白板工具栏和通话控制分成两层。录制前先确认；录制时所有人都能看到红色“录制中”提示，停止录制不会结束通话。离开通话前会确认。

## 状态

| 场景 | 表现 |
|---|---|
| 保存失败 | 标题下的保存状态变红：“未能保存 · 点按重试”，画布不被遮挡 |
| 儿童设备 | 没有发起通话、邀请和录制按钮 |

## 依赖与待决

- 需要新能力：多块白板的存储、命名和缩略图。现在只有一个固定的 `local-whiteboard`。
- 待决 O01：逐人接纳与邀请委托。原型里暂定为家长勾选成员设备。
- 待决 O02：录制同意、中途加入与儿童告知。原型里暂定为录制前确认、全员持续可见。
- 待决 O04：讲解者跟随和最小工具集；待决 O05：桌面端角色（原型里 MacBook 设备暂不可选）；待决 O06：RTC 厂商、地域和预算。
- 编辑器仍基于 Excalidraw；原型里的工具栏表达的是信息结构，实施时再确认用宿主自绘，还是配置 Excalidraw 自带的工具栏。
