# 空间

功能 ID：`space` | 设计日期：2026-09-25 | 状态：维护者 2026-09-25 确认原型，正式 UI 尚未实施 | 原型：[siyue-prototype.html](siyue-prototype.html)（跳转面板“空间”）

## 现状问题

目标列表和目标详情挤在同一个滚动页里，手机上选中一个目标只是在同一屏展开，没有层级，也没有返回。“项目”这一层看不到，进度数字无法核对。目标不能完成、归档或设置日期，也不能新增任务。当前是哪个空间只在账号页用一行字说明。同步状态是一行静态文案，家庭空间、成员和角色在界面上都没有。

## 页面

- **空间首页**：标题就是空间名，点它切换空间；标题下一直显示同步状态。先列“今天”要做的任务（可直接打勾），再列目标卡片，卡片上有进度环、下一步、完成数和目标日期。有待确认的计划草稿时，顶部出现一张提示卡。右下角按钮新建计划。家庭空间在右上角显示成员头像。
- **目标详情**：标题、目标日期、完成数、进度条、可展开的“为什么这样安排”、项目名和任务列表。任务可以直接打勾，点任务可改名称和日期，最后一行直接输入就能添加任务；已完成的任务折叠在底部。完成目标、归档目标放在右上角菜单里。
- **家庭成员**：列出姓名、角色（管理者、管理员、成员、儿童）和设备。儿童只显示设备数和监护人。另有一句话说明离线期限：最多 24 小时后需要联网确认。
- **切换空间**（底部表单）：我的空间、家庭空间、本机空间，每项写明类型、同步状态和你的角色，另有“创建家庭空间”入口。

## 状态

| 场景 | 表现 |
|---|---|
| 离线 | 同步行变成警示色：“离线 · 更改已保存在本机”；家庭空间加上“22 小时内需联网” |
| 待同步 | “3 项更改等待同步” |
| 同步冲突 | 顶部卡片写出冲突的任务和两边各改了什么，按钮“保留这台的”“用另一台的” |
| 只读成员 | 顶部说明只读，打勾和添加按钮全部不可用，没有新建按钮 |
| 空空间 | 空状态说明，外加两个按钮：新建计划、在对话里聊聊 |

## 依赖与待决

- 家庭空间范围的数据读写、同步状态和冲突详情都还没有接到客户端，现在只有“原本机空间”和“账号空间”两种范围。
- 邀请成员的方式和有效期还没定（add-account-family-spaces 的待决项）。
- 契约里有目标日期和任务日期（`targetDate`、`dueLocalDate`），但现有界面都没有入口；原型为两者都加了入口。
