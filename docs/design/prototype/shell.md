# 导航

功能 ID：`shell` | 设计日期：2026-09-25 | 状态：维护者 2026-09-25 确认原型，正式 UI 尚未实施 | 原型：[siyue-prototype.html](siyue-prototype.html)（跳转面板“导航”）

## 现状问题

侧栏只有品牌名、新建对话、“我的空间”、白板、对话列表和设置齿轮。它看不出当前在哪个空间，个人、本机和家庭空间之间没有切换入口，对话列表也不区分空间。账号入口藏在设置页里。

## 新结构

侧栏从上到下依次是：品牌名和新建对话按钮、当前空间卡片（点开是切换空间的底部表单）、三个功能入口（对话、目标、白板）、当前空间的最近对话，底部是本人头像（进入账号）和设置齿轮。对话、目标和白板都跟随当前空间。

手机上侧栏是从左侧滑出的抽屉；iPad 上侧栏常驻，宽 300pt，右侧显示当前功能页面。计划创建、发起通话用模态页打开；白板编辑和通话占满全屏，不显示侧栏。

## 依赖与待决

- 对话按空间持久保存需要新能力，现在的对话只存在内存里。
- 创建家庭空间的流程还没有设计，原型中只放了入口。
- 设置页不在本轮重构范围内。
