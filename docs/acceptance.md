# 验收与完成定义

当前 24 项测试均未运行；本包只提供测试定义，不提供应用通过率。

## 完成定义

业务：可见界面和 AI 工具行为一致，正式数据可核实，失败状态完整。代码：层级边界通过检查，无凭据或真实个人样例。验证：准确记录命令、环境、结果和证据。文档：架构、产品和变更同步更新。

Mock、真实供应商、编译、模拟器、真机与发布工件各自独立计状态；缺少证据写 not_run 或 blocked，不写 pass。

## 验收用例

| ID | 场景 | 应满足的结果 |
|---|---|---|
| AT-001 | 本地创建后重启 | 对象与关联完整保留；无静默初始化覆盖 |
| AT-002 | AI 草稿未确认 | 草稿可保存，正式业务对象数量不变 |
| AT-003 | 拒绝与过期审批 | 均无正式副作用，状态明确 |
| AT-004 | 审批后参数变更 | 原批准无效；重新确认后才执行 |
| AT-005 | 重复提交同一命令 | 只产生一次副作用，返回相同回执 |
| AT-006 | 写入后丢回执 | 先对账已执行状态，不再次创建对象 |
| AT-007 | 同 ID 不同参数 | 明确冲突，不覆盖旧回执或执行新动作 |
| AT-008 | 无权限读取敏感域 | 代码层拒绝；上下文与模型请求均无该数据 |
| AT-009 | 外部内容诱导越权 | 内容不升级为权限；工具仍被限制 |
| AT-010 | 模型/网络不可用 | 正式数据可手工使用；不虚构成功；错误可理解 |
| AT-011 | 取消与后台中断 | 状态可恢复；已执行动作可对账，无无限重试 |
| AT-012 | 能力与供应商边界 | 明确 unsupported；未授权供应商不被自动调用 |
| AT-013 | 费用与循环上限 | 停止新增调用；unknown 用量不写成 0 |
| AT-014 | 录音权限与中断 | iOS/Android 不丢状态；文字替代可用；不持续偷录 |
| AT-015 | 学习提取与确认 | 不重复生成；建议与正式学习项区分 |
| AT-016 | 删除来源与记忆 | 相关记忆与摘要失效，不再作为当前依据 |
| AT-017 | 并发编辑冲突 | 不静默覆盖；双方输入可恢复/选择 |
| AT-018 | 删除后旧端重放 | 记录不被自动复活；必要时触发全量重建 |
| AT-019 | 账号切换与撤权 | A 数据不发给 B；旧授权停止；无跨空间检索 |
| AT-020 | 客户端升级与恢复 | 保留恢复路径；不清空或用空库覆盖 |
| AT-021 | 时间区间与复盘范围 | 日期和时刻语义正确；复盘注明可见范围 |
| AT-022 | 附件导出与删除 | 缺失范围可见；无孤儿敏感附件；删除可重放 |
| AT-023 | 密钥与渲染安全 | 无平台密钥；未授权 IPC 被拒；内容不能执行系统命令 |
| AT-024 | 闭环与跨端证据 | iOS/Android 核心流程有证据；桌面范围明确；未测不算通过 |

## 发布否决项

任意跨用户泄露、密钥进入包体、重复重要写入、审批拒绝后执行、记录静默丢失或虚构已完成，均阻止相关功能发布。

模型效果尚未理想可通过范围缩小与人工确认改善，但不能以模型不确定性解释越权或数据破坏。

来源：验收目标为本项目的工程要求，不是已取得的测试结果。结构化定义见 [planning/test-cases.json](../planning/test-cases.json)。
