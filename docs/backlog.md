# 工作包清单

共 20 项：SY-001 至 SY-018 为初始发布路径，SY-019/020 为后续扩展。所有状态均为 planned；这些不是已经创建的 GitHub Issues。

## SY-001 · 建立三端工程骨架与版本记录

里程碑：M1 | 优先级：P0 | 状态：in_progress

依赖：无

验收：
- 采用 pnpm workspace；移动为 Expo，桌面为 Electron + React，服务端为 Node。
- 记录 React/Expo/RN/Electron/Node 的版本与可执行命令。
- 完成当前可用环境的构建；iOS/Android 真机与 Windows 未运行项如实标注。

## SY-002 · 定义纯 TypeScript 领域与命令契约

里程碑：M1 | 优先级：P0 | 状态：in_progress

依赖：SY-001

验收：
- Goal/Project/Task/Draft/Receipt 具备 schema 与行为约束。
- 共享层不导入 UI、Node 文件系统、Electron 或具体数据库驱动。
- 同一命令可从手工 UI 与 AI 路径调用；有跨空间引用拒绝测试。

## SY-003 · 验证 SQLite 与同步候选并记录 ADR

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-001, SY-002

验收：
- 在隔离原型验证 RN 与 Electron 的持久化、事务和原生构建。
- 比较 PowerSync 与受限备选的冲突、账号隔离、许可和退出路径。
- 写 ADR-004 的采用/不采用结果及版本证据；不以 demo 代替生产同步验收。

## SY-004 · 实现本地存储、事务与升级恢复

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-002, SY-003

验收：
- 业务数据与活动/命令回执按选定适配器一致提交。
- 重启不丢失；升级失败不覆盖唯一原始数据。
- 测试重复命令、部分失败、删除标记与恢复入口。

## SY-005 · 建立秘密存储、数据授权与日志边界

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-001, SY-002

验收：
- 区分本地保存、同步、AI 外发与后台用途。
- 模型平台 Key 不进入 App；个人 Key、日记、录音不进入日志或 Git。
- 受限 IPC/服务端鉴权接口有非法参数与越权测试。

## SY-006 · 接入 AI SDK 候选与 Mock Provider

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-001, SY-002, SY-005

验收：
- 确定性 Mock 能覆盖文本、工具、审批、失败与取消。
- 实际模型凭据由部署者提供；使用前配置供应商和预算。
- 能力不足明确返回错误，不自动换未授权供应商。

## SY-007 · 实现 AgentRun 持久状态与事件协议

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-004, SY-006

验收：
- 事件带 runId、seq 与 schemaVersion。
- 断流、取消、重启和未知结果分别处理，不伪造完成。
- 记录模型/策略版本与数据截止范围，不持久化隐藏思维链。

## SY-008 · 实现草稿、审批与幂等业务执行

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-004, SY-005, SY-007

验收：
- 确认绑定参数 hash、对象版本、space 与有效期。
- 拒绝/过期/撤销不写正式表；参数变化需新审批。
- 相同 commandId 返回同一结果，丢回执后先对账再重试。

## SY-009 · 完成目标—项目—任务的最小闭环

里程碑：M1 | 优先级：P0 | 状态：planned

依赖：SY-004, SY-008

验收：
- AI 生成可编辑草稿；确认后出现真实对象。
- 手动创建、编辑、完成和归档在离线状态可用。
- iOS 核心流程、Android 同一路径与 Electron 最小入口具备验收证据。

## SY-010 · 实现活动时间线和可管理记忆

里程碑：M2 | 优先级：P0 | 状态：planned

依赖：SY-004, SY-005, SY-009

验收：
- 正式活动与审计分开；数字从正式数据计算。
- 候选记忆与确认事实分开；用户可编辑和删除。
- 撤销来源后相关摘要/检索投影失效。

## SY-011 · 验证语言学习录音与音频中断

里程碑：M2 | 优先级：P0 | 状态：planned

依赖：SY-001, SY-005, SY-006

验收：
- iOS/Android 真机录音、回放、权限拒绝、耳机/中断有实际记录。
- 无录音权限时文字路径可完成练习。
- 音频外发用途明确；ASR 不宣传成客观发音评分。

## SY-012 · 实现学习会话、纠错候选与复习队列

里程碑：M2 | 优先级：P0 | 状态：planned

依赖：SY-009, SY-010, SY-011

验收：
- 练习关联目标或项目；原始会话与模型评估分开。
- 词汇与纠错以候选展示，确认后进入复习。
- 重复上传/提取不重复生成已确认项，时长由计时记录。

## SY-013 · 实现有来源的用户触发复盘

里程碑：M2 | 优先级：P0 | 状态：planned

依赖：SY-010, SY-012

验收：
- 统计与模型文本分开，提供记录依据与覆盖范围。
- 未同步、缺失或不足的数据明确说明。
- 复盘可修改保存；不自动成为新个人事实或新任务。
