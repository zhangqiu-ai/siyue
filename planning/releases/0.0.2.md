# 0.0.2

状态：已发布

维护者：项目维护者；版本确认日期：2026-09-25；发布日期：2026-09-25。标签：`v0.0.2`；[GitHub Release](https://github.com/zhangqiu-ai/siyue/releases/tag/v0.0.2)。

0.0.2 是从未发布的 0.0.1 开发流中提取的账号生命周期小版本。只发布已经完成实现和验收的线上注册、登录、会话恢复与账号注销；五设备视频通话、共享白板及其他未完成能力继续留在 [0.0.1 历史计划](0.0.1.md)，不进入本版本。

| 会话安全保存、重启恢复与退出 | 已验收 | [线上账号生命周期](../../docs/evidence/online-account-lifecycle-2026-09-25.md) |

## 发布门槛

- [x] 公网 API、真实邮件服务和实际邮箱完成注册、重启恢复、退出、密码登录、注销与注销后拒绝登录。
- [x] Electron Playwright 线上生命周期测试通过。
- [x] iPhone 与 iPad 模拟器完成中文和英文注册、恢复及注销；验证码快速输入压力测试通过。
- [x] 0.0.2 版本、iOS build 2 与 Android versionCode 2 在配置及生成工件中核对。
- [x] 根测试、类型检查、构建、Playwright、OpenSpec 与 release 检查通过。
- [x] 已连接开发 iPhone 完成签名 Release 编译、安装和启动验证。
- [x] 提交、远端标签与 GitHub Release 创建成功并复核。

## 不在本版本

- Android 真机与商店分发。
- App Store 提交、生产分发证书和 TestFlight。
- 真实 Apple 登录撤销调用。
- 五设备视频通话、共享白板和录制存档。
- 0.0.1 中其他尚未完成或尚未覆盖完整平台矩阵的能力。

这些范围保持原有状态，不因 0.0.2 发布而标记完成。

服务端迁移保留注销历史清理所需的房间引用表，但 0.0.2 不注册房间 HTTP 路由。家庭邀请、监护关系和儿童设备服务仅用于注销依赖检查及维护任务；生产启动路径不公开这些尚未发布的路由。

发布候选的完整自动化、双平台 bundle 与真机证据见[0.0.2 发布收口证据](../../docs/evidence/release-0.0.2-2026-09-25.md)。
